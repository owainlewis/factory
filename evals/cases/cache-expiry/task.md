Implement Cache(capacity, clock), with put(key, value, ttl) and get(key). capacity must be a positive integer excluding bool, otherwise raise ValueError. clock is a callable returning monotonic numeric seconds. Keys are strings; values are deepcopy-compatible. ttl must be a finite int or float excluding bool; invalid ttl raises ValueError without changing cache contents or recency. A valid put replaces the key and makes it most recently used; ttl <= 0 removes that key instead. Expiry is measured from put, and a value is expired when clock() >= its deadline. get returns an independent deep copy and marks a live entry most recently used, or raises KeyError for missing/expired keys. Reads do not extend expiry. Purge expired entries before capacity eviction; if still full, evict the least recently used live key. Store an independent deep copy on put too. Assume clock never moves backward and deepcopy succeeds.

Keep the public API in app.py. Use only the Python standard library. Preserve existing behavior except where this task explicitly changes it.
