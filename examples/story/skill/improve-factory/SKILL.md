# Improve factory

1. Review the factory pull requests from the last 14 days and what people
   changed or commented on them.
2. List the problems people corrected in 2 or more pull requests.
3. Edit `.claude/skills/factory/SKILL.md` so the factory avoids them, and open a
   pull request that links each change to its evidence.

Never merge. A person reviews every change to the factory.
